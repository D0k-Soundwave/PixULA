Brush Shape Designer

Hand-edit the round brush mask for any size 1-32, then export it for review. Not part of the app - dev tool only. Every shape is exactly N x N pixels for a size-N brush - never larger, never cropped - and uses the one centring that actually fits that size (a true single centre pixel for odd sizes, a true centre 4 for even sizes). The only thing that can genuinely vary at a fixed size is how many pixels wide the circle's cap is at each of the four edges it must fully reach; up to three such variations are offered when more than one exists, and only one when that's all there is. The radio button under whichever one you want picks the shape that actually gets exported.
